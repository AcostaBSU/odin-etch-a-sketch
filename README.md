# Odin Etch-a-Sketch

A JavaScript focused project that generates an interactive grid with mouseover event listeners to imitate an Etch-a-Sketch by changing background color of any boxes the mouse moves over.

## Description

[Odin Etch-a-Sketch](https://www.theodinproject.com/lessons/foundations-etch-a-sketch) is project in the foundation portion of the [Odin Project](https://www.theodinproject.com/paths)
designed to give learners an opportunity to do hands-on JavaScript development with a focus on DOM manipulation and events by implementing an interactive UI to imitate an Etch-a-Sketch. The project consists of a small HTML file, small CSS file, and a JavaScript file. The HTML merely consists of a slider container for the slider and its value, along with links to the CSS and JavaScript files, which is where most of this project lives. The CSS file contains critical flexbox styling to allow the grid to grow and shrink without adversely affecting how the grid is displayed. Finally, the JavaScript file is ultimately responsible for creating, adding, and updating the interactive grid element (and its subsequent supporting elements) in the DOM, along with the necessary event listeners to make the grid interactive.
